Git

  • git branch <имя_ветки> - переводится как "создать новую ветку".
  • git checkout - переводится как "переключение". С ее помощью можно переключаться между ветками.
  • git branch -d <имя_ветки> - переводится как "удаление ветки".
  • git init - расшифровывается как "git initialize", что переводится как "создать репозиторий".
  • git clone - переводится как "«клонировать репозиторий".
